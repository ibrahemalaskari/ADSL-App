ADSL-App 0.8.4 — تثبيت تحديث
1) أوقف الجسر (Ctrl+C).
2) احتفظ بنسخة من مجلد المشروع الحالي: cp -a ~/adsl-app ~/adsl-app-backup-before-0.8.4
3) فك الضغط إلى مجلد مؤقت وانسخ الملفات إلى مجلد المشروع الحالي، دون حذف data أو أي ملف قاعدة بيانات.
4) من مجلد المشروع نفّذ: npm test
   المتوقع: 215 اختباراً ناجحاً.
5) شغّل الجسر بالطريقة المعتادة.
6) واجهة التشخيص الموسعة متاحة عبر /db/diagnostics.
لا تُجرِ اختبار reset أو restore على قاعدة تشغيلية.
