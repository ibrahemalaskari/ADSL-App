ADSL-App 0.8.5 — تثبيت أو تحديث على Termux

المتطلبات: Termux من مصدر موثوق واحد، وNode.js 22.5 أو أحدث.

1) فك الحزمة في مجلد مستقل أولاً، ولا تستبدل مجلد التشغيل القديم مباشرة:
   cd ~
   unzip -o ~/storage/downloads/adsl-app-0.8.5.zip -d ~/adsl-app-0.8.5
   cd ~/adsl-app-0.8.5

2) تحقق من Node وشغّل الاختبارات:
   node --version
   npm test
   المتوقع في نهاية الاختبار: # pass 236 و # fail 0.

3) قبل نقل قاعدة التشغيل، أوقف الجسر القديم وخذ نسخة احتياطية من قاعدة SQLite:
   cp ~/adsl-app/data/adsl.sqlite ~/storage/downloads/adsl-before-0.8.5.sqlite
   (إذا كان مسار قاعدة البيانات مختلفاً، انسخ المسار الفعلي بدلاً منه.)

4) شغّل النسخة الجديدة:
   node bridge/server.js
   ثم افتح في متصفح الهاتف:
   http://127.0.0.1:8787/adsl-app.html

5) عند استخدام قاعدة البيانات القديمة، أوقف الجسر، وانسخ ملف SQLite الاحتياطي إلى مجلد data في النسخة الجديدة باسم adsl.sqlite، ثم شغّل الجسر. سيُجري التطبيق ترقية المخطط إلى الإصدار 5 دون حذف الجداول السابقة.

ملاحظات أمان وتشغيل:
- لا تحذف مجلد النسخة القديمة أو قاعدة بياناتها حتى تتحقق من فتح البيانات في النسخة الجديدة.
- لا ترفع API الراوتر إلى الإنترنت. فعّل خدمة API محلياً فقط عند الحاجة، وقيّدها بعنوان الهاتف، ثم عطّلها بعد الانتهاء.
- الجسر يستمع على 127.0.0.1 فقط.
- أول قراءة VLAN هي نقطة أساس؛ يلزم قراءة لاحقة لحساب الفروقات.
- هذه الحزمة لم تخضع لقبول ميداني على جهاز المستخدم أو راوتره. راجع RELEASE_NOTES-0.8.5.md وREADME_TERMUX.md.
