ADSL-App 0.8.3

1) أوقف الجسر الحالي (Ctrl+C).
2) احتفظ بنسخة احتياطية من المشروع: cd ~ && cp -a adsl-app "adsl-app-backup-before-0.8.3-$(date +%Y%m%d-%H%M%S)"
3) فك الحزمة في مجلد مؤقت وانسخ محتوياتها إلى ~/adsl-app.
4) من ~/adsl-app نفذ: npm test
   المتوقع: 214 اختباراً ناجحاً.
5) أنشئ نسخة SQLite: node tools/sqlite-backup.mjs create
6) شغّل الجسر: npm run bridge
7) بعد تشغيل الواجهة، endpoint التشخيصي GET /db/diagnostics متاح محلياً.

لا تُجرِ اتصالاً بالراوتر أو استعادة بيانات كجزء من الاختبارات المبدئية. لا يوجد اختبار ميداني في هذا الإصدار.
